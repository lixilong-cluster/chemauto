# ChemAuto 7.1.2

ChemAuto 7.1.2 is the integrated archival release used for the doctoral-dissertation software appendix. It combines the validated command-line workflow with the Gaussian Log Browser GUI and frequently used cluster-computing utilities.

## Highlights

- Robust Gaussian parsing, including wrapped archive fields and multi-Link1 jobs.
- GUI structure/SCF inspection, global relative-energy ranking, and CSV/Excel export.
- Stable/Stable=Opt, Gen/GenECP, VDE/ADE, PES/DOS, multi-frame XYZ, and multi-Link1 GJF tools.
- Validated legacy PyMOL renderer restored as the default Excel structure-image backend.
- Complete portable Windows build workflow with regression tests and PyMOL smoke tests.
- Independent Reference Explorer included in the complete suite.

## Build

On Windows 10/11 with 64-bit Python 3.11:

```bat
BUILD_FROM_SCRATCH.bat
```

## External requirements

Origin/OriginPro is required for automatic DOS plotting. Remote `.chk → .fchk` requires OpenSSH, a network connection, and a user-configured server account.
